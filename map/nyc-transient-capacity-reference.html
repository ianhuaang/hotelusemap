NYC Transient Capacity Reference

Deal team reference · August 2026

The Data Stack

The transient capacity map classifies buildings using two automated data sources that determine tier, plus additional sources for enrichment and confirmation.

SourceWhat It Tells UsRole
PLUTO (NYC Dept of City Planning) Building class — hotel (H01–H09), mixed-use (RM, RC), residential, commercial, etc. Updated annually by DCP, but can lag behind real-world changes by 1–3 years. Tier input
HPD Registration (Housing Preservation) Class A (permanent residential) and Class B (transient) unit counts per building. Renewed annually by building owners — the most current signal of active transient capacity. Tier input
Certificate of Occupancy (DOB) Issue date, type (final/temporary), dwelling unit count Enrichment only
DOB NOW Job Filings Alteration CO filings with job descriptions — captures explicit conversion language (e.g., "convert hotel to residential") Confirmation layer for reversion window

The C of O metadata we pull via the DOB API does not include the occupancy group classification. The actual C of O PDF — which shows floor-by-floor use breakdown and whether transient use is explicitly authorized — is only available through manual lookup on DOB BIS, one building at a time.

Not Excluded: Residential Zoning

159 of the 237 transient capacity buildings are in residential zoning districts where hotel use is "not permitted." These are not excluded because:

  • HPD Class B registration is the legal authority for transient occupancy under the Multiple Dwelling Law, renewed annually by building owners.
  • The zoning restriction on hotel use applies to establishing new hotel use (the 2021 CPC special permit requirement), not to continuing existing authorized transient occupancy.
  • These buildings' Class B rooms are already legally authorized for transient stays. The zoning district describes what new uses can be added, not what existing lawful uses must stop.

Not Excluded: Rent-Stabilized Units

Many transient capacity buildings also contain rent-stabilized Class A (residential) units. These are not excluded because rent stabilization applies to the permanent residential units, not to the Class B transient rooms. The two are separate legal categories under the Multiple Dwelling Law. A building can have rent-stabilized apartments and operable Class B transient rooms side by side.

DOB Occupancy Check on Partial Signal

To test whether HPD registration was lagging for partial signal buildings, we ran DOB occupancy lookups (SODA dataset ic3t-wcy2) on the top 50 partial signal buildings by unit count — prioritizing those with no HPD data and RC/RH building classes.

Result: zero R-1 or J-1 transient hits. All 50 buildings returned R-2 (residential), COM (commercial), B (business), or E (educational) occupancy codes. These buildings are genuinely non-transient — the partial signal reflects mixed-use building classes, not unregistered transient capacity. No buildings were promoted from partial to transient based on this check.

What Each Tier Means Operationally

Legal Transient

The building has confirmed existing transient/hotel capacity. It can operate as transient housing as-of-right — no special permit needed under the Citywide Hotel Text Amendment (Dec 2021), because the use is already established. The C of O should already reflect transient occupancy.

Regulatory path: Verify the C of O is current and reflects transient use. From there it's standard — DOB permits for renovation, hotel operating license, fire safety compliance. No land use approvals required.

Class B (Split-Use)

HPD confirms both Class A apartments and Class B transient rooms in the same building. Real transient capacity exists, but it's mixed with residential.

How the split works: The A/B split is not always by floor. It can happen three ways:

  1. By floor — most common in NYC. Lower floors residential, upper floors transient, or vice versa.
  2. By wing or section — larger buildings with a residential wing and a hotel wing sharing the same address.
  3. By unit designation — individual units on the same floor registered differently. Common in buildings that partially converted.

HPD data only gives us the counts (e.g., 45 Class A + 20 Class B) but not where they are. The C of O PDF has the floor-by-floor breakdown. For Kasa, contiguous floors of Class B rooms are much easier to manage than scattered units across a residential building.

PLUTO Building Class and Expansion Limits

A common question: if PLUTO doesn't classify the building as a hotel, does that create a problem for operating the Class B floors?

No — for existing Class B rooms. PLUTO building class is descriptive, not prescriptive. It reflects the predominant use of the building, not every authorized use within it. A building that's mostly residential with some Class B transient rooms will show a residential building class in PLUTO, but those Class B rooms are still legally authorized for transient use because HPD has them registered. You can operate them without changing the PLUTO classification.

Yes — for expanding beyond the existing Class B footprint. If you want to convert additional floors from residential (Class A) to transient (Class B), that's a change of use, which triggers:

  1. A DOB alteration permit for the change of use
  2. The special permit requirement under the Hotel Text Amendment
  3. Eventually an updated PLUTO building class reflecting the new predominant use
Practical ceiling: In a Class B split-use building, you're limited to the transient rooms HPD already recognizes — unless you're willing to go through the CPC special permit process. This makes the HPD Class B room count the hard cap on transient capacity for these buildings.

Building Class Lag

PLUTO building class is assigned by the Department of Finance based on Certificate of Occupancy filings and periodic reassessment. It can lag actual use by 1-3 years, and sometimes indefinitely. DOF publishes tentative assessment rolls each January and final rolls each May. When a building's use changes, the classification updates only when: (a) DOF processes a new C of O, (b) the next reassessment cycle catches it, or (c) the owner requests reclassification.

The Phillips Club at 155 West 66th Street illustrates this perfectly: HPD registers the building as 100% transient (0 Class A, 151 Class B), but PLUTO still classifies it as RC (residential-commercial) — not a hotel building class. The building has operated as a fully transient property for years, but DOF's classification hasn't caught up.

What this means for the pipeline: A building's PLUTO class is suggestive, not definitive. An H-class building is a strong signal, but the absence of H-class does not mean the absence of transient use. HPD and DOB data are more current than PLUTO building class, which is why the pipeline uses all three and weights HPD Class B most heavily. When evaluating a specific building, treat the building class as a hint and the C of O as the authority.

Partial Signal

The building class in PLUTO suggests possible mixed use (RM, RC), but HPD has no Class B registration to confirm transient capacity. This is the weakest automated signal — needs manual verification.

Why HPD Might Not Have Data

A building can have a mixed-use building class in PLUTO but no HPD Class B registration for several reasons:

  1. It's just not transient — the most common case. RM/RC covers commercial/residential mixed-use broadly. A building with retail on the ground floor and apartments above is RM but has zero transient capacity.
  2. HPD doesn't regulate it — HPD only registers buildings with 3+ residential units. A primarily commercial mixed-use building may not appear in HPD's system at all.
  3. Grandfathered use — older buildings operating under legacy C of O provisions may have transient rooms never formally registered with HPD as Class B.
  4. Recent conversion not yet recorded — a building that just completed a change-of-use may not have updated HPD registration yet. DOB approved it, C of O reflects it, but HPD lags.
  5. SRO or edge cases — some Single Room Occupancy buildings function like transient housing but are classified differently in HPD's system.
Where the deal team finds value: Cases 2–4 are where hidden transient capacity may exist. A manual C of O check on those buildings could uncover capacity the automated pipeline misses. Case 1 is the majority, which is why the tier defaults to low confidence.

How Flex-Stay Operators Work Within Residential Buildings

Operators like Sonder, Placemakr, and Mint House use two distinct legal paths in NYC. Understanding these explains why some buildings show up in our pipeline and others don't.

Path 1: Buildings with Transient C of O (Legal)

The operator leases or manages units in a building that already has transient authorization — an R-1 occupancy group in the C of O and/or HPD Class B registration. The DOB filings for these conversions are explicit. At Sonder's Nash property (222 East 39th Street), a 2011 DOB filing reads: "Renovation and establishment of existing hotel use within residential building" with the occupancy changing from RES to J-1 (transient residential). HPD eventually registered 66 Class B rooms. This is a fully legal transient operation that our pipeline catches.

Path 2: 30+ Day Stays in Residential Buildings (Legal, But Invisible)

NYC Multiple Dwelling Law requires the host to be present for stays under 30 days in Class A residential buildings. Since January 2023, Local Law 18 enforces this through OSE registration. Operators who don't want to navigate this requirement simply book stays of 30 days or longer — which is legal in Class A residential without any special license, operator registration, or change of use. These buildings show zero transient signal in our pipeline because they are technically still operating as residential.

What this means for the pipeline: Buildings on Path 1 — those with formal transient authorization — show up through HPD Class B, DOB R-1 occupancy, or transient keywords in DOB filings. The pipeline catches these. Buildings on Path 2 (30+ day stays in Class A) are invisible to every public dataset because they are legally residential operations. The prior operator list is the only way to flag these buildings, which is why the ground truth file is a critical pipeline input.

Pushing Partial Signal to Legal Transient

Nothing in the current data pipeline can promote a partial signal building automatically. To confirm transient capacity, the deal team needs evidence outside our two automated sources:

  1. Pull the actual C of O PDF from DOB BIS — if it shows hotel/transient occupancy group, that's the confirmation PLUTO and HPD couldn't provide.
  2. Check if HPD registration is lagging — some buildings have transient rooms but HPD data hasn't caught up. A direct HPD inquiry or building visit could confirm Class B rooms exist.
  3. DOB job filings — an active or completed alteration permit for change-of-use to transient would be a strong signal, even if HPD hasn't updated yet.

How to Read This Data

A filing that says "convert hotel to residential" or "change of use from R-1 to R-2" is strong evidence that the building was a hotel and is being (or was) converted. These are the strongest reversion candidates — the DOB filing independently confirms what PLUTO and HPD suggest.

Large dwelling unit increases (0 to 150+ units) on buildings with hotel building class are also a conversion signal, even without explicit language — a hotel being subdivided into apartments produces a jump in dwelling unit count.

What this means for the deal team: When evaluating a reversion window building, check whether DOB NOW shows a conversion filing. If it does, you have three independent signals (PLUTO hotel class + HPD Class A with no Class B + DOB conversion filing) all pointing the same direction. That's a building where the reversion path is well-documented and the as-of-right deadline is real and actionable.

Remaining Blind Spots

Even with DOB R-1 occupancy integrated, the pipeline has data limitations that no public dataset can resolve. These are worth noting for deal teams doing manual diligence.

Blind Spot What It Means Why We Can't Fix It Workaround
OSE / Local Law 18 registration The Office of Special Enforcement maintains a registry of legal short-term rentals and hotel operators. A building could have an active OSE permit with no trace in HPD or DOB. No public dataset exists on NYC Open Data. OSE does not publish a machine-readable registry. FOIL request to OSE, or check individual buildings via 311 inquiry.
Certificate of Occupancy — occupancy group A C of O specifying R-1 occupancy group would be definitive proof of transient authorization. This is the gold standard. Neither the legacy C of O dataset (bs8b-p36w) nor the DOB NOW dataset (pkdm-hqz6) includes the occupancy group field. They have dwelling units and building class, but not R-1/J-1 classification. Pull individual C of O PDFs from DOB BIS for high-priority buildings. The occupancy group is printed on the document itself.
Zoning lot mergers / air rights transfers A building may hold transient rights via a zoning lot merger with an adjacent hotel parcel. These rights don't appear under the building's own BBL in any dataset. Zoning lot configurations are recorded in deed restrictions and ULURP filings, not in a structured public dataset. Check ACRIS for zoning lot development agreements on high-interest parcels.
Variance / BSA approvals The Board of Standards and Appeals can grant variances allowing transient use in zones where it's otherwise prohibited. These override standard zoning. BSA decisions are published as individual PDFs, not as a queryable dataset with occupancy classifications. Search BSA online portal by address for high-priority buildings.
Bottom line: The pipeline captures the two strongest public signals — HPD Class B registration and DOB R-1 occupancy classification. Together these cover the vast majority of legal transient buildings. The blind spots above are edge cases that require manual diligence on a per-building basis, and are most relevant for buildings that show partial signals (hotel building class, prior operator, temporary C of O) but don't have HPD or DOB confirmation.

The Special Permit Framework

The Citywide Hotel Text Amendment (December 9, 2021) requires a City Planning Commission special permit for new hotel development across most of NYC. This is a lengthy, expensive land use process.

Buildings already classified as Legal Transient are not affected — they have established use rights and operate as-of-right. This is the core value proposition of the transient capacity map: identifying buildings where transient use is already legal, bypassing the special permit entirely.

Key dates:
Dec 9, 2021 — Hotel Text Amendment adopted (special permit required for new hotels)
Dec 9, 2027 — Reversion window closes (converted hotels lose as-of-right reversion)

The ULURP Process

The CPC special permit triggers a Uniform Land Use Review Procedure — a formal, multi-step public review that any new hotel or major hotel expansion must navigate. Understanding the steps, cost, and timeline explains why almost nobody applies.

Timeline (7 Steps)

2. DCP certification Department of City Planning Variable DCP certifies the application as complete. Triggers the formal ULURP clock.
3. Community Board Local CB 60 days Public hearing. Advisory recommendation only, but politically significant.
4. Borough President BP office 30 days Advisory recommendation.
5. CPC vote City Planning Commission 60 days Public hearing and vote to approve or deny.
6. City Council Full Council 50 days Can approve, modify, or disapprove. The local Council member's position carries decisive weight.

Total end-to-end: 24–30 months. The formal ULURP stages alone run 5–9 months by statute, but pre-certification (environmental review, DCP back-and-forth) often doubles the elapsed time.

Approval Track Record

Effectively near-zero volume. Zero applications were filed in the first full year after adoption (through December 2022). The first identified application was 10 Rockefeller Center (Little Nell / Aspen Hospitality, 136-room office-to-hotel conversion), filed 2023, with borough president recommendation August 2024. 509 Madison Avenue (C 260065 ZSM) filed August 2025. The special permit regime functions primarily as a deterrent — the cost, timeline, union labor requirements, and political uncertainty make the process unattractive to most developers.

Union labor requirement: The 2021 amendment also requires union construction labor and collective bargaining for hourly operational staff at any hotel that obtains a special permit. This adds cost and limits operator flexibility — a significant additional deterrent beyond the permitting expense itself.

Grandfathering and Nonconforming Use

The 2021 text amendment created a hard before/after line. Everything on this map with pre-2021 transient use holds a grandfathered entitlement that cannot be replicated without the ULURP process above.

Legal Basis

Hotels existing as of December 9, 2021 (the amendment adoption date) are conforming uses. They may continue operating, be structurally altered, or be enlarged under 20% of floor area without triggering the special permit requirement. The legal framework is the NYC Zoning Resolution, particularly ZR 52-61 (discontinuance of nonconforming uses).

Key Rules

RuleDetailImplication
Two-year discontinuance If transient hotel use is discontinued for a continuous two-year period, the building loses its grandfathered status. Must obtain a CPC special permit to resume hotel operations. The primary risk for dormant buildings on this map. Any building sitting idle needs to be tracked against this clock.
Restoration safe harbor Hotels that existed on December 9, 2021 may be restored to transient use regardless of discontinuance length, as long as restoration happens before December 9, 2027. Creates urgency — only 16 months remain. After 2027, the standard two-year clock applies strictly.
Minor enlargement Grandfathered hotels can expand by up to 20% of floor area without a special permit, provided there is no zoning lot enlargement. Allows modest renovations and additions without triggering ULURP.
Casualty reconstruction If a grandfathered hotel is damaged or destroyed, it may be rebuilt without a special permit. Insurance / disaster scenario — the entitlement survives the physical building.
December 2027 deadline: This is the single most time-sensitive fact in the transient capacity landscape. Any building with pre-2021 hotel use that has been sitting idle needs to reactivate before December 9, 2027, or risk permanent loss of its hotel use rights. After that date, two years of discontinuance = game over without a $300K–$750K+ special permit.

Local Law 18 (Short-Term Rental Regulation)

LL18 is separate from the hotel special permit — it regulates short-term rentals in residential buildings, not hotel zoning. But it's deeply relevant because it explains why Class B status is so valuable and why hotel demand is structurally supported.

Requirements

Enforced since September 5, 2023, LL18 requires anyone offering a rental under 30 consecutive days in a Class A dwelling to:

  • Register with the Mayor's Office of Special Enforcement (OSE)
  • Be physically present in the unit during the guest's stay
  • Limit occupancy to two guests
  • Not rent the entire unit (guests must share the space with the host)

Booking platforms must verify a valid OSE registration number before processing any transaction.

The Class B Exemption

HPD Class B multiple dwellings are explicitly exempt from LL18. OSE maintains a published list of Class B buildings. This is the regulatory carve-out that makes Class B status so valuable — it's a license to operate transient stays under 30 days without the host-presence, guest-cap, and no-whole-unit restrictions that apply to everyone else.

Critical nuance: The building must carry an actual HPD Class B occupancy classification, not merely a Department of Finance tax class starting with "B" (which is unrelated). This is why the HPD Class B signal on this map is definitive — it directly corresponds to the LL18 exemption.

Market Impact

Short-term rental listings dropped over 90% when enforcement began. Airbnb estimated the regulations cut 95% of its net NYC revenue. This has been structurally bullish for hotel operators: supply that competed with hotels has been largely eliminated, concentrating demand into licensed hotel inventory. For buildings on this map, the combination of the hotel special permit (blocking new supply) and LL18 (eliminating informal supply) creates a double moat.

Enforcement

Fines range from $100–$5,000 per violation for hosts; platforms face up to $1,500 per unverified transaction. In May 2025, OSE filed its first lawsuit under LL18's penalty provisions. In February 2026, OSE filed a multi-million-dollar suit against a landlord operating illegal short-term rentals in rent-stabilized buildings.

Legal Status

Airbnb and three individual hosts sued to block LL18 before it took effect. In August 2023, NYS Supreme Court Justice Arlene P. Bluth dismissed all challenges, ruling the city acted within its authority. No subsequent legal challenge has succeeded. A new City Council proposal (Intro. 1107) has reopened policy debate, but LL18 remains fully in effect. An Albany Law Review paper has argued LL18 may be unconstitutional under the dormant Commerce Clause, but that theory has not prevailed in court.

Political Durability

The investment thesis for existing transient capacity depends on the hotel special permit remaining in place. Here's the political analysis.

Origin

The Hotel Trades Council (now Hotel and Gaming Workers Union) was the primary driver. Championed under Mayor de Blasio, who had close ties to HTC. The stated rationale was preventing hotel overdevelopment in residential neighborhoods; critics called it a mechanism to require unionization as a condition of hotel development. The City Council voted 46–1 on December 9, 2021.

Legal Challenges

New Yorkers for Tourism Inc. (represented by Kasowitz Benson Torres) sued before the amendment was adopted, calling it "arbitrary, capricious," and an unconstitutional giveaway to HTC. The lawsuit did not succeed in blocking the amendment. No court has struck down the special permit requirement. A separate 2025 legal challenge relates to the SAFE Hotels Act (a distinct law covering hotel safety/staffing), not the zoning amendment itself.

Current Political Landscape

  • No active effort to repeal or modify. Mayor Adams has not proposed rolling it back.
  • "City of Yes for Housing Opportunity" (approved December 2024) focused on residential density and did not touch the hotel special permit.
  • REBNY has criticized the amendment but has not mounted a focused repeal campaign.
  • HTC remains politically influential in City Council elections, making repeal politically costly.
  • 2026 is an election year — no Council member has incentive to champion reversal.

Durability Assessment

Very durable. Reversal requires a City Council vote (majority of 51 members) through the full legislative process. The 46–1 adoption vote, failed legal challenges, HTC's continued political influence, and zero repeal efforts in 4+ years all point to this being a permanent feature of NYC zoning. The supply constraint on new hotel development should be treated as a long-term structural given in any investment thesis involving existing transient capacity.

Bottom line for deal teams: The regulatory moat around existing transient capacity is deep and durable. LL18 eliminated informal short-term rental supply. The 2021 text amendment froze new hotel development. Both have survived legal challenges. The buildings on this map hold entitlements that are worth more today than when they were first established — and that value increases every year that the special permit regime remains in place.

Rent Stabilization and Transient Capacity

Many buildings on this map have Class A residential units alongside Class B transient rooms. If any of those Class A units are rent-stabilized, that affects what an operator can do with the building. This section covers the constraints.

Can Stabilized Units Coexist with Class B Rooms?

Yes — and many NYC buildings have exactly this split. HPD registers Class A (permanent residential) and Class B (transient) units separately within the same building. The rent stabilization status of Class A units has no legal bearing on the Class B transient rooms. An operator can run hotel operations in the Class B portion without affecting stabilized tenants in the Class A portion.

Can Stabilized Units Be Converted to Hotel Use?

No — this is illegal under multiple overlapping laws.

  • Multiple Dwelling Law (MDL) Section 4: Class A units are for "permanent residence purposes" (30+ consecutive days). Converting to transient use is unlawful.
  • NYC Admin Code Sec. 28-210.3: Prohibits converting permanent-residence units to any other use.
  • Local Law 18: Requires registration for sub-30-day rentals in Class A buildings; effectively bans short-term use.
  • Enforcement: Fines range from $1,000 to $25,000 per violation. OSE has sued landlords for converting stabilized units to illegal hotel rooms.

Can Stabilized Units Be Deregulated?

Effectively, no. The Housing Stability and Tenant Protection Act of 2019 (HSTPA) permanently repealed the two primary deregulation pathways:

  • High-rent vacancy deregulation — Abolished. Previously, when a stabilized tenant vacated and the legal rent exceeded the threshold (~$2,775), the landlord could permanently deregulate. An estimated 170,000 units were lost this way before HSTPA.
  • High-rent / high-income deregulation — Abolished. Previously allowed deregulation when tenant income exceeded $200K and rent exceeded the threshold.
  • Vacancy bonus — The 20% automatic rent increase upon turnover was repealed.
  • IAI-driven deregulation — Individual Apartment Improvements can no longer push rents above the threshold to trigger deregulation, because the threshold mechanism itself was eliminated.

The remaining pathways to remove units from stabilization are building-wide and extreme: demolition, substantial rehabilitation of a deteriorated building (75%+ of systems completely replaced), or genuine conversion to commercial use. None are practical for a hotel operations play.

Legal Status of HSTPA

Constitutionally settled. CHIP v. City of New York challenged HSTPA as a regulatory taking under the Fifth Amendment. District court dismissed (2020), Second Circuit affirmed (2023), and SCOTUS denied certiorari (October 2023). G-Max Management v. State of New York made a similar challenge; SCOTUS denied cert again (November 2024). The law is not at risk.

Deal evaluation rule: Any acquisition model for a building with rent-stabilized units must assume permanent stabilization of all currently regulated units. There is no practical pathway to deregulate individual units. The Class B transient rooms are the opportunity; the stabilized Class A units are a fixed constraint. Underwrite accordingly — the building's hotel revenue comes only from the Class B portion.

Migrant Shelter Re-Designation Risk

At peak, ~16,000 hotel rooms across ~160 NYC hotels served as migrant shelters. If Kasa evaluates a building that was recently a shelter, IC will ask whether the city can take it back.

How Hotels Became Shelters

Voluntary contracts — not eminent domain, not forced seizures. The city contracted with the Hotel Association of New York City (HANYC) as a third-party administrator. Individual hotel owners opted in. Emergency executive orders (renewed every five days since October 2022) suspended shelter regulations to allow hotels to operate as shelters without meeting normal requirements.

No owner was forced to participate. There is no evidence of the city using eminent domain, permit revocation threats, or coercion. Hotels joined because guaranteed full-occupancy payments at market rates made financial sense, especially for struggling properties.

Can the City Force Re-Designation?

No. The Callahan v. Carey consent decree (1981) requires the city to shelter anyone who requests it, but it says nothing about how the city acquires shelter capacity. Callahan imposes an obligation on the city, not on private property owners. The city has always met it through voluntary contracts, public facilities, and purpose-built shelters — never through seizure.
